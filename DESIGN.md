# Desktop design

Operate mode. A desktop game library intended to sit beside a running game. Ink surfaces, warm white type, restrained acid-green actions and status indicators. Manrope for interface text; Space Grotesk for titles and numerical values. Real Steam artwork carries the visual personality.

Persistent narrow sidebar. Search and library controls remain at the top. The catalog uses genuine game cover art, clear support labels, and paginated results. A supported game's page puts connection status, launch action, and cheats first. Unavailable trainers show a useful local request action instead of disabled pretend controls. Keyboard access and visible focus apply everywhere.

Appearance follows Windows by default, with saved light and dark overrides in settings. Light mode uses warm white surfaces, dark green text and a darker green for readable accent text; primary actions retain the lime fill. Artwork remains in a dark color context. The app and overlay share the preference. The overlay uses a bounded grid with a single scrolling cheat list; the page, header and footer do not scroll.

Cheat profiles live in a disclosure on each game page. Users name snapshots of active cheats and multipliers, apply or replace them, and select an optional default for new sessions. Profiles never replay currency or resource actions.

Build directly as a functional desktop application, matching the user's selected functional-app path. 1280×820 main design target, minimum 1024×700; content adapts to window width. No mock testimonials, fake support counts, or implied online service.
